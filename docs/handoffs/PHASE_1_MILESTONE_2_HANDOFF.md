#### 4. Architecture and Design Decisions

Reuse `AlpacaREST`, `xnys_snapshot`, `BronzeAcquisition`, `HistoricalRequest` and `acquire_historical` directly. Only the injectable transport is synthetic; calendar generation, normalization, filesystem writes, Parquet encoding and terminal-manifest publication are real local execution.

The existing distinctions remain: response bytes are authoritative; normalized timestamp labels are UTC; equivalent bars retain separate observation IDs; absent provider IDs/revisions are not invented; execution completion is separate from market completeness. `complete` means successful pagination exhaustion. Failed requests cannot become successful manifests. No arrival-order correction or implicit gap filling is introduced.
